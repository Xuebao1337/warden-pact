# 凋零舞团 / Wither Dance Party — Forge 1.8.9

一个独立的搞怪模组：默认按 **G**，在前方召唤 **5 只凋零造型的舞者**，伴随三头摇摆、骨架扭动、上下蹦迪、音符粒子和轻柔的音符盒旋律。再次按该键立即解散。

Minecraft 1.8.9 没有坚守者，本版沿用凋零主题。舞者使用原版凋零模型和纹理，但属于独立的友好生物，没有真实凋零的爆炸、凋零头颅、破坏方块或 Boss 血条。

## 安装与使用

1. 安装 Minecraft Java **1.8.9**、**Forge 11.15.1.2318**，使用 **Java 8**。
2. 把 build/libs/witherdance-forge-1.8.9-1.0.0.jar 放进游戏 mods 目录。多人联机时，服务端及需要显示舞者的客户端均需安装。
3. 进入世界，找到周围约 6 格、上方约 4 格的空地，按 **G** 召唤。
4. 按键可在“选项 → 控制 → 凋零舞团”中修改。聊天、背包和菜单中不会触发召唤。

每人最多一队，持续 **30 秒**，召唤冷却 **5 秒**；再次按键随时解散。和平难度可以使用。主人死亡、退出、切换维度或离开超过 64 格会清理舞者。空间不足时整队不生成，也不消耗冷却。不会强制加载区块；舞者不保存到世界，不掉落物品或经验。

此模组的 ID 是 witherdance，可以与同仓库的装备/坐骑模组 witherpact 一起安装。其他 Minecraft/加载器版本应使用各自的 JAR。

## 构建与检查

    ./party-forge-1.8.9/build.ps1 -JavaHome 'C:/path/to/jdk8'
    ./party-forge-1.8.9/build.ps1 -Offline -Smoke -ModelCheck

构建使用 Gradle 2.14.1 / ForgeGradle 2.1，优先复用仓库内工具和 .gradle-legacy 缓存。脚本在结束时恢复原来的 JAVA_HOME 和 GRADLE_USER_HOME。服务端检查跳过客户端素材下载，并在检查结束后重新生成重混淆的正式 JAR。

服务端检查涵盖召唤/解散、冷却、多人隔离、和平难度、无伤害/无头颅/不破坏地形、舞台移动与阻挡、30 秒过期、主人状态清理、空间失败、生成取消回滚和空网络包。模型检查直接构造原版 ModelWither 派生模型，检查三个头和三节骨架的实际旋转、有限数值和重复调用稳定性。检查源码分别在独立 smoke、modelCheck 源集中，不会打进正式 JAR。
