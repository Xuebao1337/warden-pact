# 坚守者舞团 · Warden Dance Party

Minecraft Java **26.2 / NeoForge 26.2.0.95 / Java 25** 的独立搞怪模组，版本 **1.0.0**。与仓库里的助战契约版使用不同的 mod ID，可以一起安装。

## 安装与操作

1. 将正式文件 wardendance-neoforge-26.2-1.0.0.jar 放入 26.2 NeoForge 实例的 mods 文件夹。
2. 单人直接进入世界；多人服务器需要服务器和每个客户端都安装这个模组。
3. 找一片有坚实地面、约 4 格高空间的空地，按 **G** 召唤 **5 只坚守者舞者**。
4. 它们在你前方优先排成半圆，摆臂、摇头、踢腿、左右转身、踩拍蹦跳；头顶冒彩色音符，同时播放简短的音符盒旋律。
5. 再按一次 **G** 全体下班。不手动解散时，**30 秒**后自动消失。

按键可在“选项 → 控制 → 按键绑定 → 坚守者舞团”修改。如果 G 与其他模组冲突，换成空闲键即可。聊天、背包、菜单中输入 G 不会召唤。旋律音量受“唱片机/音符盒”声音分类控制。

## 舞团规则

- 每位玩家最多一组，连续按键不会叠加。两次成功召唤之间至少间隔 5 秒；解散始终立即生效。
- 舞者固定在选定的舞台跳舞，不追着玩家走。主人离舞台超过 64 格、死亡、退出或切换维度时退场。
- 和平难度也能用；旁边的其他玩家能看到舞蹈、听到音乐。
- 不攻击、不放音波、不施加黑暗、不妨碍睡觉，不产生掉落或经验。
- 舞者免疫伤害、不会被推动；不写入世界存档，不强制加载区块。
- 周围放不下完整 5 只时取消整次召唤并提示，不留下半支舞团，也不消耗召唤冷却。
- 地形改变挡住蹦跳空间时，受影响舞者会退场。

此版本专注跳舞，不另带助战剑、装备、工具和坐骑。需要这些玩法可另外安装本仓库原有的 26.2 Warden Pact。

## 构建和验证

Windows 安装 Java 25 JDK 后，在仓库根目录运行：

    ./party-26.2/build.ps1
    ./party-26.2/build.ps1 -Tests -Offline

首次构建需要下载 Gradle 和 NeoForge 依赖；离线命令要求依赖已缓存。脚本复用仓库的 Gradle 缓存，服务端测试跳过大型客户端资源下载。

也可使用本目录 Gradle Wrapper 的 build、checkDanceAnimation、runGameTestServer 任务。自动验证包括真实服务端 GameTests、网络请求编解码与服务端处理函数，以及客户端原版模型零件的舞蹈和发光层对齐检查。模型检查不需要启动图形客户端，不能替代游戏内人工画面和按键手感验证。正式 JAR 不包含测试模组。
