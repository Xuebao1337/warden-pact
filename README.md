
# 坚守者契约 · Warden Pact

**26.2 NeoForge 搞怪舞团版**：独立工程位于 [party-26.2](party-26.2/README.md)。按 **G** 召唤 5 只坚守者摆臂、摇头、蹦迪，带音符和旋律；再按一次解散，30 秒自动退场。与助战契约版可并存。

**Forge 1.8.9 凋零契约版**：独立工程位于 [forge-1.8.9](forge-1.8.9/README.md)。剑命中召唤友方凋零，另有可飞行的凋零坐骑；保留装备能力、三种附魔与头盔持续夜视，外观换为紫黑冥骨风格。[外观预览](docs/wither-forge-1.8.9-preview.png)。

**Fabric 26.3 版**：独立工程位于 [fabric](fabric/README.md)，包含召唤、回响装备、三种附魔和幽匿战兽坐骑；**1.3.0 为八件回响装备加入自带能力**：侦测、反震、疾行、摔伤减免，以及连锁采矿、伐木和 3×3 铺路、耕作。下文安装与配置说明针对 NeoForge 26.2（仍为 1.1.0）。

Fabric **1.3.1** 为回响头盔增加穿戴期间持续生效的夜视。

Fabric **1.3.2** 更新装备与坐骑外观：原版下界合金风格的甲片倒角、冷色金属和少量青色嵌纹。共享装备贴图同步更新，玩法与夜视保持不变。[外观预览](docs/texture-preview.png)。

Minecraft **Java 版 26.2 / NeoForge 26.2.0.95** 模组。用剑命中敌对生物，召唤一只属于你的友方坚守者助战。**1.1.0** 新增回响盔甲、工具和三种附魔。

## 安装

1. 在启动器中安装 **Minecraft 26.2 + NeoForge 26.2.0.95 或同一 26.2 分支的更新版本**。游戏使用 **Java 25**。
2. 将发布页的 `wardenpact-1.1.0.jar` 放进这个游戏实例的 `mods` 文件夹。升级时先移出旧版 JAR，不能同时保留两个版本。不要放入 `-sources.jar`。
3. 启动游戏。多人游戏时，客户端和服务器都要安装本模组。

本模组不能装到 Fabric、Forge、基岩版或其他 Minecraft 版本中。

## 玩法

- 默认任何带 `minecraft:swords` 标签的剑都能触发，包括原版剑和本模组的召唤剑。
- **左键命中僵尸、骷髅等敌对生物并造成伤害**，即可召唤；空挥、射箭、砍动物或玩家不会触发。
- 坚守者立即攻击你命中的怪物；继续用剑命中其他怪物，会指挥现有坚守者更换目标。
- 每位玩家最多一只。默认持续 **60 秒**，召唤冷却 **20 秒**，多次攻击不会刷新存活时间。
- 没有指定目标时，优先攻击主人周围 **24 格**内的敌对生物；没有敌人时走路跟随主人。
- 保留原版坚守者的近战和音波攻击。不会攻击玩家、已驯服的宠物或友方坚守者，也不会给玩家施加黑暗效果或妨碍睡觉。
- 附近必须有安全落脚点和约 3 格高的空间；空间不足会提示，且不消耗召唤冷却。
- 召唤物是临时助战单位，不掉落物品和经验，不写入世界存档。主人死亡、离线、切换维度，以及召唤物所在区块卸载或退出世界时会消失。
- 默认与原版坚守者一样，不能攻击原版坚守者。会把实现原版 `Enemy` 接口的怪物视为敌人，其中包括末影人等平时可能保持中立的怪物；不会主动伤害动物、村民等被动生物。

## 专属召唤剑

创造模式的“战斗用品”中可以找到 **坚守者召唤剑**，也可以开启作弊后使用：

```mcfunction
/give @s wardenpact:summoning_sword
```

在工作台同一列从上到下放置：

```text
回响碎片
下界合金剑
钻石
```

得到一把坚守者召唤剑。属性相当于下界合金剑，带原创青色像素贴图。此有序合成会消耗材料，不继承材料剑的附魔或自定义名称。

1.1.0 起，也可以用下面的锻造台配方升级召唤剑，保留原有附魔和名称。

## 回响盔甲和工具

新增 **回响头盔、回响胸甲、回响护腿、回响靴子**，以及 **回响镐、回响斧、回响锹、回响锄**。

- 基础耐久、护甲值、韧性、击退抗性和工具采掘等级采用下界合金标准；整套盔甲提供 20 点护甲和 12 点韧性。
- 掉落的装备物品不会被火或岩浆烧毁，拥有原创幽匿青色物品贴图；盔甲还有对应的穿戴贴图。穿戴者仍会受到火焰和岩浆伤害。
- 镐可以采掘黑曜石；斧可以去皮，锹可以铺路，锄可以耕地，按原版工具规则消耗耐久。
- 可正常附魔，并可在铁砧中用 **回响碎片或下界合金锭**维修新增的回响装备。
- 创造模式中，盔甲位于“战斗用品”，工具位于“工具与实用物品”。

在锻造台中，从左到右放入：

| 模板 | 基础装备 | 添加物 | 结果 |
| --- | --- | --- | --- |
| 下界合金升级锻造模板 | 对应的下界合金盔甲或工具 | 回响碎片 | 对应的回响装备 |
| 下界合金升级锻造模板 | 下界合金剑 | 回响碎片 | 坚守者召唤剑 |

锻造会消耗模板、基础装备和回响碎片，**保留基础装备的附魔、自定义名称和已损耗耐久**。新增的八件装备都能用这种方式获得。

## 新增附魔

| 附魔 | 最高等级 | 适用物品 | 效果 |
| --- | --- | --- | --- |
| 契约共鸣 | III | 剑 | 每级让新召唤的坚守者多存在 15 秒，召唤冷却减少 3 秒，最低 1 秒 |
| 幽匿守护 | IV | 盔甲 | 每件每级减少 2% 来自敌对生物的伤害；正常满套 IV 合计 32% |
| 回响采掘 | III | 采掘工具（包括原版工具） | 主手持有时，每级提升 20% 方块挖掘速度；III 为 60% |

- 三种附魔均加入普通附魔台、常规附魔书交易和随机附魔战利品的附魔池；获取仍遵循对应原版机制，不保证每次出现。实验性村民交易重平衡使用单独的交易池。
- 可以通过附魔书和铁砧使用；可与原版对应装备附魔搭配，原版附魔之间的冲突规则保持不变。
- 契约共鸣 III 在默认配置下，让新召唤持续 **105 秒**，冷却变为 **11 秒**。指挥已有坚守者不会刷新存活时间或更改已经开始的冷却。
- `anySwordSummons = false` 时，仍然只有专属召唤剑能召唤；给其他剑附契约共鸣不会绕过这个配置。
- 幽匿守护只保护穿戴者免受敌对生物造成的伤害，包括敌对生物发射的弹射物；不减少摔落、岩浆、玩家攻击或绕过附魔的特殊伤害，也不代替原版护甲机制。
- 回响采掘只在主手生效，切换到副手或收起工具后失效；不会改变正确工具要求和方块掉落条件。

开启作弊后，可使用以下指令快速体验：

```mcfunction
/give @s wardenpact:echo_helmet
/give @s wardenpact:echo_chestplate
/give @s wardenpact:echo_leggings
/give @s wardenpact:echo_boots
/give @s wardenpact:echo_pickaxe
/give @s wardenpact:echo_axe
/give @s wardenpact:echo_shovel
/give @s wardenpact:echo_hoe
```

把对应物品拿在主手，然后使用相应附魔指令（盔甲也需要先拿在手里）：

```mcfunction
/enchant @s wardenpact:contract_resonance 3
/enchant @s wardenpact:sculk_guard 4
/enchant @s wardenpact:echo_mining 3
```

## 配置

首次进入世界后，编辑游戏实例的 `config/wardenpact-server.toml`，退出并重新进入世界使配置生效。也可将该文件放入某个世界的 `serverconfig` 目录，覆盖该世界的设置：

```toml
anySwordSummons = true
cooldownSeconds = 20
lifetimeSeconds = 60
defendRadius = 24
```

将 `anySwordSummons` 改为 `false` 后，只有专属召唤剑能够召唤。服务器由服主设置这些选项。

## 构建与开发

需要 **JDK 25**；JRE 或 Java 17 无法编译本项目。第一次构建需要网络下载 Gradle、Minecraft 和 NeoForge 依赖。

Windows 上可运行自动查找 JDK 25 的脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

已经正确配置 `JAVA_HOME` 时，使用标准 Gradle 命令：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat runGameTestServer
```

产物：`build/libs/wardenpact-1.1.0.jar`。

`src/gameTest` 包含服务端游戏测试，覆盖召唤与目标切换、数量和冷却限制、玩家和宠物保护、到期清理、实际击杀怪物、跟随、空间不足处理，以及装备属性、真实工具交互、附魔可用性、强化召唤、实际减伤、采掘速度和锻造时组件保留。测试模组和测试场地不会打包进正式模组。

主要代码在 `src/main/java/dev/wardenpact`；贴图、语言、合成表和物品标签在 `src/main/resources`。

项目以 NeoForge 官方 MDK 为基础，使用官方 Mojang 类名；游戏本体及其映射仍受各自许可证约束。项目新增代码和原创贴图使用 MIT 许可证。
