# 坚守者舞团 · Minecraft 26.3 Fabric

独立搞怪模组，默认按 **G** 在面前召唤 **5 只跳舞的坚守者**，再按 G 解散。按键可在「选项 → 控制 → 按键绑定 → 坚守者舞团」修改。

- 舞团会摆臂、踢腿、摇头、转身和蹦跳，发光胸腔随身体一起动。
- 彩色音符粒子搭配原创音符盒短旋律，音量受「唱片机 / 音符盒」控制。
- 每队持续 **30 秒**，召唤间隔 **5 秒**；每位玩家同时只能有一队。
- 离开舞台 64 格、死亡、退出或换维度时自动清理。
- 舞团不会攻击、释放黑暗或音爆，不掉落物品、经验，不存入世界；和平模式也可以使用。
- 需要有坚实地面和足够头部空间。空间不足时整队取消，且不消耗冷却。

## 安装

需要 Minecraft **26.3**、Java **25**、Fabric Loader **0.20.1 或更高**、Fabric API **0.167.0+26.3 或兼容的 26.3 版本**。将 wardendance-fabric-26.3-1.0.0.jar 放入 mods。多人服务器及参与玩家都要安装本模组和 Fabric API。

这个舞团版与原有装备、工具、附魔、坐骑工程分开；使用与游戏版本和加载器匹配的文件。

## 构建和验证

正常构建运行 ./build.ps1；运行服务端测试使用 ./build.ps1 -Tests -Offline。

build 会编译正式模组，并运行真实模型骨骼动画断言和无界面的 Fabric GameTest 服务端；-Tests 可显式追加服务端测试任务。测试覆盖召唤数量、再次解散、冷却、到期、和平模式、无攻击 / 黑暗、空间不足回滚、玩家退出 / 死亡 / 距离清理、独立队伍、空字段网络请求、舞台位置和新增障碍物处理。测试代码和测试地图不会进入正式 JAR。

已通过 **14 项 GameTest（13 项舞团测试 + 1 项原版测试）**及 **605 项模型动画断言**。正式 JAR 的 Java 25 字节码、语言键、归档完整性和测试代码隔离也已核对。对应结果记录在仓库 docs/dance-fabric-26.3-validation.json。

尚未进行 GPU 客户端画面与物理按键的人工验收；服务端行为和模型数值检查不等同于人工画面验收。
